计划中：打开 Nocturne 的链接

Nocturne 计划支持从浏览器、电子邮件、聊天软件或其他应用中的链接打开指定的笔记本页面。操作系统将使用 nocturne: 链接类型启动 Nocturne，并告知它要打开哪个页面。根据操作系统和浏览器的不同，打开应用前可能会要求你确认。

此功能目前尚不可用。Nocturne 目前不会向操作系统注册 nocturne:，也不会在收到外部链接时跳转到指定页面。复制 Nocturne 页面链接并不表示现在就能从浏览器打开它。

链接注册计划

  • Windows 安装程序：计划在安装时注册 Nocturne，并在卸载时移除此注册。
  • Windows 便携 ZIP：计划提供单独的注册 Nocturne 链接操作，由你主动运行，并提供取消注册的方法。仅解压 ZIP 不会注册链接。
  • macOS：在 Nocturne 应用包中声明链接类型。
  • Linux：为该链接类型安装桌面应用关联。

注册只会告诉操作系统由哪个应用接收链接。Nocturne 还必须找到对应的笔记本和页面，在应用已运行时处理链接，并在找不到笔记本或页面时清楚地说明情况。这些也都是计划功能的一部分。
