# Открытие страницы по ссылке

## В планах: ссылки для открытия Nocturne

В планах Nocturne: открытие определённой страницы блокнота по ссылке из браузера, почты, чата или другого приложения. Операционная система будет использовать тип ссылки `nocturne:`, чтобы запустить Nocturne и передать ему страницу для открытия. В зависимости от системы и браузера перед запуском приложения может появиться запрос на подтверждение.

Эта возможность **пока недоступна**. Nocturne ещё не регистрирует `nocturne:` в операционной системе и не открывает указанную страницу по внешней ссылке. Копирование ссылки на страницу Nocturne не означает, что её уже можно открыть в браузере.

## Как планируется регистрировать ссылки

- **Установщик Windows:** регистрировать Nocturne при установке и удалять регистрацию при удалении приложения.
- **Портативный ZIP для Windows:** добавить отдельное действие **Зарегистрировать ссылки Nocturne**, которое пользователь запускает сам, и способ отменить регистрацию. Простое распаковывание ZIP ссылку не зарегистрирует.
- **macOS:** указать тип ссылки в пакете приложения Nocturne.
- **Linux:** установить ассоциацию приложения рабочего стола с этим типом ссылки.

Регистрация лишь сообщает операционной системе, какое приложение может получить ссылку. Nocturne также должен найти нужные блокнот и страницу, обработать ссылку, если приложение уже запущено, и понятно сообщить, если блокнот или страница не найдены. Это тоже входит в планы.
